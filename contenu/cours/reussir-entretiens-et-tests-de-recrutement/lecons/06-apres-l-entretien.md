L'entretien est terminé. Beaucoup de candidats pensent qu'il ne reste plus qu'à attendre. En réalité, ce qui se passe après peut encore faire la différence.

## Le message de remerciement

Dans les vingt-quatre heures, envoyez un court message de remerciement par e-mail (ou par le canal utilisé pendant le recrutement) :

> Bonjour Madame Diallo,
> Je vous remercie pour notre entretien d'hier concernant le poste de gestionnaire de stock. Notre échange sur la réorganisation de votre entrepôt a renforcé mon envie de rejoindre votre équipe. Je reste à votre disposition pour tout complément d'information.
> Bien cordialement,
> Moussa Traoré

Court, personnalisé avec un détail de l'échange, sans insister. Peu de candidats le font : c'est une façon simple de se démarquer.

## Faire son propre bilan

Juste après l'entretien, notez :

- les questions posées, surtout celles qui vous ont surpris ;
- ce qui s'est bien passé ;
- ce que vous auriez aimé dire autrement ;
- les informations apprises sur le poste et l'entreprise.

Ce bilan enrichit votre préparation pour les prochains entretiens.

## Relancer, sans harceler

Si le recruteur a annoncé un délai et qu'il est dépassé de quelques jours, une relance polie est acceptable :

> Bonjour Madame Diallo, je me permets de revenir vers vous concernant le poste de gestionnaire de stock. Je reste très intéressé et disponible pour toute étape supplémentaire.

Une relance, éventuellement deux, espacées d'une semaine. Au-delà, passez à autre chose.

## Rebondir après un refus

Un refus fait partie du parcours, même pour les meilleurs candidats. Quelques réflexes :

- **Répondez poliment** et remerciez : le recruteur pourrait vous recontacter pour un autre poste.
- **Demandez un retour** : « Auriez-vous un conseil qui m'aiderait à progresser ? » Tous ne répondront pas, mais certains retours sont précieux.
- **Ne le prenez pas comme un jugement sur votre valeur** : un autre candidat avait peut-être simplement plus d'expérience sur un point précis.

::: a-savoir
Chaque entretien vous entraîne pour le suivant. Les candidats qui finissent par décrocher un poste sont souvent ceux qui ont persévéré, ajusté leur préparation et continué à postuler.
:::

## Accepter une offre

Si vous recevez une offre, prenez le temps de vérifier : le salaire, le type de contrat, la période d'essai, les horaires, les avantages. Demandez une confirmation écrite. N'hésitez pas à poser des questions avant de signer.

::: a-vous Vos modèles de suivi
Rédigez avec l'aide de l'IA trois modèles personnalisables : un message de remerciement, une relance et une réponse à un refus avec demande de retour. Gardez-les dans vos notes, prêts à être adaptés.
:::

## Et maintenant ?

Vous préférez travailler pour plusieurs clients plutôt que pour un seul employeur ? Le cours « Freelancing : vendre ses compétences en ligne » vous montre comment.

- Envoyez un message de remerciement personnalisé dans les vingt-quatre heures.
- Faites votre bilan après chaque entretien.
- Une ou deux relances polies, pas plus.
- Un refus est une étape : remerciez, demandez un retour, continuez.
:::
