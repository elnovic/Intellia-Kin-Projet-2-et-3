# Charte graphique en code

Ce dossier traduit la charte graphique Intellia Kin (version 1.0, 2026) en
éléments utilisables par les interfaces.

| Fichier | Contenu |
|---|---|
| `tokens.css` | Couleurs, polices, tailles, espacements, composants de base |
| `logo/intellia-kin-logo-slogan.png` | Logo officiel avec le slogan |
| `logo/intellia-kin-logo.png` | Logo sans slogan, fond transparent |

## Couleurs

| Nom | Code | Usage |
|---|---|---|
| Bleu Nuit Kin | `#0A2540` | Titres, structure, fonds sombres |
| Bleu Électrique | `#0066FF` | Boutons, liens, accents |
| Cyan Tech | `#00C9A7` | Réussite, croissance, chiffres clés, liserés |
| Ardoise Sombre | `#1A202C` | Texte principal |
| Gris Fond Doux | `#F8FAFC` | Arrière-plans, cartes, tableaux |

## Polices

| Usage | Police | Repli |
|---|---|---|
| Titres | Plus Jakarta Sans | Inter |
| Texte | Inter | Roboto, Arial |
| Chiffres, code | JetBrains Mono | Fira Code |

## Règles à respecter

- Icônes en trait fin, angles légèrement arrondis, en Bleu Électrique ou Cyan Tech.
- Photos de vraies personnes en situation de travail ; pas de robots ni de
  cerveaux 3D.
- Logo : zone de protection égale à la hauteur du « I » d'Intellia, largeur
  minimale 120 px à l'écran, jamais déformé ni recoloré, sans ombre ni dégradé ajouté.
- Sur fond sombre, utiliser la version inversée du logo (à fournir).
